# docrank

A Claude Code plugin that enforces a working method instead of asking for it:
guard hooks, read-only judges, gates before a push, docs that outrank code.
One file per repository, `.claude/docrank.json`, adapts it.

Status: in development. Nothing is published and nothing is installable yet.

Configuration keys: [docs/config.md](docs/config.md). Claude Code behaviours
the plugin depends on: [docs/harness-facts.md](docs/harness-facts.md).
