# docrank P0 — the plan

## Context

The roadmap (`~/Desktop/docrank-roadmap.md`) proposes to test whether outside
teams adopt review against their own specifications. Its P0 is technical, and
was checked against the code on `main` (`17fdc05`, 490/490 tests green):

- `lib/check-drift-pairs.mjs:53` (`unit.startsWith(code)`): an entry
  `src/payments/` does not pair the unit `src/payments`, which is named without
  a trailing slash. Lines 62 and 65 do the same with the `docDrift.unpaired`
  keys.
- `templates/pre-push:16`: `catch {}` turns an unreadable or invalid
  `.claude/docrank.json` into `{}`, which leaves the hook `off` and exits 0
  silently. The Bash guard, by contrast, refuses everything on an invalid
  config (`lib/hook.mjs` `configFor`).
- `skills/init/SKILL.md:95`: says a plugin's `Stop` and `WorktreeCreate` hooks
  are "not proved". `docs/harness-facts.md` facts 2 and 3 record them as PROVED
  LIVE. The limits that remain are Claude Code < 2.1.300 and
  `--worktree --tmux`.
- `init` never mentions `judges.routes`, and proposes `docs.precedence` only
  when a document declares its rank. Without `docs.precedence`, `spec-arbiter`
  returns `unproven` and stops, so after a plain `init` the arbiter is off.

The user's decisions: the scope is the **whole P0**; P1/P2 stay out until the
pilot has results. The demo ships as a **`/docrank:demo` skill** with a
versioned example in the plugin.

Outcome sought: 0.1.1 (fixes) and 0.2.0 (the arbiter switched on from `init`,
plus a demo that reproduces a finding in under 10 minutes), both proved live
and recorded.

## How the work runs

- Repository convention: the plan is versioned in English as
  `docs/plans/2026-11-20-docrank-p0.md` in the first PR, checked slice by
  slice, and leaves the tree when done (as `726d0b5`).
- Each slice has its own branch and worktree, cut from an up-to-date
  `origin/main`, and a PR against `main`. Merges are the user's.
- Each slice is built by a fresh subagent, not a fork, given this plan,
  `CLAUDE.md` and the files it names as context. Fix rounds resume that same
  subagent.
- Conventional commits with a scope, and the session's `Co-Authored-By` line.
- A slice closes with its evidence — tests, green CI and the commands' output
  — before the next one starts.
- Tags, GitHub releases and marketplace installation are external actions.
  They stop and are asked of the user at that moment.

    the header.
  - Tests in `scripts/run-gates.test.mjs` § `templates/pre-push`: broken JSON →
    1 with the message; `gates.run` not an array → 1; missing file → 0. The
    four current tests stay green.
- [ ] **1d · `init` fallback text.** `skills/init/SKILL.md` § 4 «Fallback
  hooks» is rewritten:
